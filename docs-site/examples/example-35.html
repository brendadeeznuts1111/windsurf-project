# 🖥️ Bun HTTP Testing Guide

*Generated on 2025-12-12T15:05:00.000Z*

## 📋 Overview

Bun's HTTP testing infrastructure provides comprehensive coverage of Node.js HTTP APIs with specialized test organization. Tests are broken down into focused, individual test files that cover specific HTTP functionality, behaviors, and edge cases.

## 🗂️ HTTP Test Organization

### Test Categories

HTTP tests are organized by functionality and testing approach:

#### Core HTTP Tests (`test/js/bun/test/parallel/`)
- **`test-http-*.ts`** - Individual HTTP functionality tests
- **`test-https-*.ts`** - HTTPS-specific functionality tests
- **Issue-specific tests** - Named after GitHub issue numbers (e.g., `test-http-10177-*`)

#### Node.js Compatibility Tests (`test/js/node/http/`)
- **`node-http.test.ts`** - Main Node.js HTTP compatibility test suite
- **`node-http-ref-fixture.js`** - Reference fixture for HTTP tests

## 🔧 HTTP Test Patterns

### Basic Server Testing

```typescript
import { createTest } from "node-harness";
import { once } from "node:events";
import { Server } from "node:http";
const { expect } = createTest(import.meta.path);

await using server = Server((req, res) => {
  res.end("Hello World");
});

server.listen(0);
await once(server, "listening");

const response = await fetch(`http://localhost:${server.address().port}`);
expect(response.status).toBe(200);
expect(await response.text()).toBe("Hello World");
```

### Request/Response Lifecycle Testing

```typescript
// Test headersSent property
await using server = createServer().listen(0);
await once(server, "listening");

fetch(`http://localhost:${server.address()!.port}`).then(res => res.text());
const [req, res] = await once(server, "request");

expect(res.headersSent).toBe(false);
const { promise, resolve } = Promise.withResolvers();
res.end("OK", resolve);
await promise;
expect(res.headersSent).toBe(true);
```

### Event Emission Testing

```typescript
// Test request completion events
await using server = http.createServer().listen(0);
await once(server, "listening");

fetch(`http://localhost:${server.address().port}`)
  .then(res => res.text())
  .catch(() => {});

const [req, res] = await once(server, "request");
expect(req.complete).toBe(false);

const closeEvent = once(req, "close");
res.end("hi");
await closeEvent;
expect(req.complete).toBe(true);
```

### Encoding and Content Testing

```typescript
// Test chunked encoding
await using server = Server((req, res) => {
  res.write("chunk1");
  res.write("chunk2");
  res.end("final");
});

server.listen(0);
await once(server, "listening");

const response = await fetch(`http://localhost:${server.address().port}`);
const text = await response.text();
expect(text).toBe("chunk1chunk2final");
expect(response.headers.get("transfer-encoding")).toBe("chunked");
```

### Error Handling Testing


## 🧪 Specialized HTTP Tests

### Constructor Testing

```typescript
// Test ES5-style constructor usage
const im = Object.create(IncomingMessage.prototype);
IncomingMessage.call(im, { url: "/foo" });
expect(im.url).toBe("");

function Subclass(...args) {
  IncomingMessage.apply(this, args);
}
Object.setPrototypeOf(Subclass.prototype, IncomingMessage.prototype);
Object.setPrototypeOf(Subclass, IncomingMessage);

await using server = new Server({ IncomingMessage: Subclass }, (req, res) => {
  if (req instanceof Subclass) {
    expect(req.url).toBe("/foo");
    res.end("success");
  } else {
    res.statusCode = 500;
    res.end("failure");
  }
});

server.listen(0);
await once(server, "listening");

const response = await fetch(`http://localhost:${server.address().port}/foo`);
expect(response.status).toBe(200);
```

## 📊 Performance and Load Testing

### Concurrent Request Testing

```typescript
// Test handling multiple concurrent requests
await using server = createServer((req, res) => {
  setTimeout(() => res.end(`response ${req.url}`), Math.random() * 100);
}).listen(0);

await once(server, "listening");

const port = server.address().port;
const requests = Array.from({ length: 100 }, (_, i) =>
  fetch(`http://localhost:${port}/${i}`)
);

const responses = await Promise.all(requests);
expect(responses.every(r => r.ok)).toBe(true);

// Verify all responses are unique
const texts = await Promise.all(responses.map(r => r.text()));
const uniqueTexts = new Set(texts);
expect(uniqueTexts.size).toBe(100);
```

### Memory Leak Testing

```typescript
// Test for memory leaks in HTTP operations
let requestCount = 0;

await using server = createServer((req, res) => {
  requestCount++;
  res.end(`request ${requestCount}`);
}).listen(0);

await once(server, "listening");

const port = server.address().port;
const initialMemory = process.memoryUsage().heapUsed;

// Make many requests
for (let i = 0; i < 1000; i++) {
  await fetch(`http://localhost:${port}`);
  if (i % 100 === 0) {
    gc(); // Force garbage collection
  }
}

const finalMemory = process.memoryUsage().heapUsed;
const memoryIncrease = finalMemory - initialMemory;

// Allow some memory increase but not excessive
expect(memoryIncrease).toBeLessThan(1024 * 1024 * 10); // < 10MB
```

### Custom Test Helpers

```typescript
function createHTTPServer(handler: (req, res) => void) {
  return new Promise<Server>((resolve) => {
    const server = createServer(handler);
    server.listen(0, () => resolve(server));
  });
}

function makeRequest(port: number, path = "/", options = {}) {
  return fetch(`http://localhost:${port}${path}`, options);
}

// Usage
const server = await createHTTPServer((req, res) => {
  res.end("custom handler");
});

const response = await makeRequest(server.address().port);
expect(await response.text()).toBe("custom handler");
```

## 📋 Best Practices

### 1. **Resource Cleanup**
```typescript
// Always use await using for automatic cleanup
await using server = createServer(handler).listen(0);
await once(server, "listening");

// Server automatically closes when test ends
```

### 2. **Isolation**
```typescript
// Use unique ports for each test
const port = Math.floor(Math.random() * 10000) + 10000;
await using server = createServer(handler).listen(port);
```

### 3. **Timing**
```typescript
// Account for async operations
const [req, res] = await once(server, "request");
// Wait for response to complete
await new Promise(resolve => res.end("done", resolve));
```

### 4. **Error Testing**
```typescript
// Test both success and error paths
test("successful request", async () => {
  // Test happy path
});

test("handles errors gracefully", async () => {
  // Test error conditions
  try {
    await makeRequest(invalidPort);
  } catch (error) {
    expect(error.code).toBe('ECONNREFUSED');
  }
});
```

## 📚 Key Concepts

1. **Test Isolation**: Each test uses unique ports and resources
2. **Automatic Cleanup**: `await using` ensures proper resource disposal
3. **Event-Driven**: Tests wait for server events before making requests
4. **Comprehensive Coverage**: Tests both client and server HTTP functionality
5. **Performance Aware**: Tests include timing and resource usage validation
6. **Cross-Version**: Tests ensure compatibility across Node.js versions

HTTP testing in Bun ensures robust, performant, and compatible HTTP implementations across all supported APIs and use cases.
